## 2. Дизассемблирование

### 2.1. Восстановленный код на языке Python
```python
def calculate_sum():
    total_sum = 0
    i = 1
    while i <= 10:
        total_sum += i
        i += 1
    return total_sum
```

### 2.2. Краткое пояснение логики
Код выполняет подсчет суммы чисел от 1 до 10. Переменная `-4(%rbp)` используется как сумматор, а `-8(%rbp)` — как счетчик цикла. Цикл выполняется с помощью команд `cmpl` и `jle`, пока итератор не превысит значение 10. Результат возвращается через регистр `%eax`.
